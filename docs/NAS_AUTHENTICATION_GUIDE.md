# 🌐 NAS / 네트워크 공유 폴더 인증 및 Robocopy 가이드

이 문서는 Synology, QNAP, ipTIME, Windows Server 등 **로그인 아이디/비밀번호가 필요한 NAS 네트워크 공유 경로(`\\NAS\Backup`)로 Robocopy 백업을 수행할 때의 동작 원리와 해결 방안**을 설명합니다.

---

## 1. Robocopy와 네트워크 인증의 핵심 원리

`robocopy.exe`는 Windows 내장 초고속 파일 복사 도구이지만, **자체적인 사용자명/비밀번호 전달 인자(Argument)가 존재하지 않습니다.**

따라서 Robocopy가 NAS 네트워크 경로(`\\192.168.0.100\Backup` 등)에 접근하려면 **Windows 운영체제(OS) 레벨에서 사전에 SMB 네트워크 세션 또는 자격 증명이 인증되어 있어야 합니다.**

---

## 2. RoboBackup Studio의 하이브리드 지원 방식

RoboBackup Studio는 상황에 따라 가장 최적화된 2가지 인증 방식을 완벽하게 제공합니다.

| 비교 항목 | 🥇 1. Windows 자격 증명 (`cmdkey`) | 🥈 2. 임시 SMB 세션 (`net use`) |
| :--- | :--- | :--- |
| **추천 시나리오** | **스케줄러 무인 백업 (추천 ⭐⭐⭐⭐⭐)** | 일회성 수동 실행 및 독립형 배치 스크립트 |
| **비밀번호 저장소** | Windows Credential Manager (OS 암호화 보관) | 스크립트 실행 시 메모리/세션에 전달 |
| **보안성** | **매우 높음** (스크립트에 평문 암호 미노출) | 보통 (스크립트 파일 내 암호 포함 가능) |
| **무인 스케줄러 호환** | **완벽 지원** (재부팅 후에도 자동 유지) | 스크립트 상단에 `net use` 명령 포함 필요 |
| **세션 수명** | 영구 보관 (수동 삭제 전까지) | 로그오프 시 또는 명시적 해제 시 종료 |

---

## 3. 상세 사용법 및 CLI 명령어

### 🥇 방법 A: Windows 자격 증명 관리자 (`cmdkey`) - [무인 스케줄러 최적]

Windows 운영체제의 보안 자격 증명 저장소에 NAS 계정을 미리 등록해두는 방식입니다. 한 번 등록해두면 이후 사용자가 로그인하지 않은 상태(무인 스케줄러)에서도 Robocopy가 자유롭게 통신합니다.

```cmd
:: 1. NAS 자격 증명 영구 등록 (IP 또는 호스트명 기준)
cmdkey /add:192.168.0.100 /user:admin /pass:MyNasPassword123!

:: 2. 등록된 자격 증명 확인
cmdkey /list

:: 3. Robocopy 실행 (자격 증명이 자동 사용됨)
robocopy "C:\MyData" "\\192.168.0.100\Backup" /MIR /MT:16 /ZB /FFT /R:2 /W:5

:: 4. 필요 시 자격 증명 삭제
cmdkey /delete:192.168.0.100
```

---

### 🥈 방법 B: `net use` 임시 세션 연결 - [배치 스크립트 실행용]

백업 직전에 세션을 연결하고, 백업 종료 후 세션을 안전하게 해제하는 방식입니다.

```cmd
:: 1. NAS 공유 폴더 세션 임시 연결
net use "\\192.168.0.100\Backup" "MyNasPassword123!" /user:"admin" /persistent:no

:: 2. Robocopy 고속 동기화 수행
robocopy "C:\MyData" "\\192.168.0.100\Backup" /MIR /MT:16 /ZB /FFT /R:2 /W:5

:: 3. 백업 완료 후 임시 세션 해제
net use "\\192.168.0.100\Backup" /delete /y
```

---

## 4. NAS 백업 필수 추천 Robocopy 옵션

리눅스 기반 파일 시스템(EXT4, Btrfs 등)을 사용하는 시놀로지/큐냅 NAS와 Windows 간 복사 시 아래 옵션이 반드시 필요합니다.

1. **/FFT (FAT File Times)**:
   - Linux SMB 파일 시스템과 Windows NTFS 간의 **2초 타임스탬프 오차**를 허용하여, 변경되지 않은 파일이 계속해서 불필요하게 다시 복사되는 현상을 완벽 방지합니다.
2. **/ZB (Restartable Backup Mode)**:
   - 복사 도중 일시적인 네트워크 끊김이나 대용량 파일 전송 중단 시 처음부터 다시 받지 않고 끊긴 지점부터 이어받기를 수행합니다.
3. **/R:2 /W:5 (재시도 횟수 및 대기시간)**:
   - 기본값(/R:1,000,000 /W:30)은 네트워크 불안정 시 프로세스가 멈춘 것처럼 보일 수 있습니다. NAS 백업 시에는 **2회 재시도, 5초 대기**로 설정하는 것이 안전합니다.
