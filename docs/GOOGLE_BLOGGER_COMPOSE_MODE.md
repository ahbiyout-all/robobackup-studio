# 🚀 [초고속 백업] Windows Robocopy 전용 GUI & C# WPF 소스 생성기 - RoboBackup Studio v2.17.0 배포

안녕하세요! 개발자 **AhBiYout**입니다.

대용량 파일이나 수십만 개의 사진, 소스 코드, 업무 문서를 외장 하드나 NAS(네트워크 공유 폴더)로 백업할 때, 윈도우 기본 복사(Ctrl+C, Ctrl+V)를 사용하다가 **속도 저하, 잠긴 파일 오류, 네트워크 끊김 시 처음부터 다시 복사되는 문제**로 답답하셨던 경험이 있으실 겁니다.

윈도우 운영체제에는 전 세계 시스템 엔지니어들이 인정하는 최고의 백업 도구인 **Robocopy(Robust File Copy)** 가 기본 내장되어 있습니다. 하지만 수백 개에 달하는 복잡한 커맨드라인(CLI) 옵션(`/MIR`, `/MT:16`, `/ZB`, `/FFT`, `/R:1`, `/W:1` 등) 때문에 일반 사용자가 다루기는 쉽지 않았습니다.

이를 완벽하게 해결하기 위해 **마우스 클릭만으로 Robocopy의 모든 최고급 성능을 이끌어내고, 실제 C# WPF(MVVM) 소스 코드까지 100% 자동 생성해 주는 오픈소스 고성능 백업 도구 "RoboBackup Studio v2.17.0"** 를 공개합니다!

---

## 🌟 RoboBackup Studio 주요 핵심 기능 7선

### 1. ⚡ 멀티스레드(`/MT:1~128`) 기반의 압도적인 복사 속도
- 일반 윈도우 탐색기 복사 대비 **최대 5배~10배 이상의 경이적인 백업 속도**를 자랑합니다.
- CPU 코어 수에 맞추어 최적의 멀티스레드 동시 복사를 원클릭으로 활성화할 수 있습니다.

### 2. 🛡️ 사용 중인 잠긴 파일도 100% 무중단 복사 (VSS 볼륨 섀도 복사본)
- Outlook PST, 실행 중인 가상머신(VM), 열려 있는 엑셀/워드 문서 등 **"다른 프로세스가 사용 중"** 이라는 이유로 실패하던 파일들을 **윈도우 VSS(Volume Shadow Copy Service)** 엔진과 연동하여 안전하게 실시간 스냅샷 캡처합니다.

### 3. 🧩 순수 창작 5대 코어 DLL 엔진 탑재
- **RoboDiffEngine**: 복사 전 원본과 대상의 차이점을 사전 스캔하여 시간과 바이트를 미리 예측
- **RoboVssProvider**: 윈도우 네이티브 VSS 볼륨 스냅샷 무중단 백업 공급자
- **RoboSyncWatch**: 스마트 디바운스 큐 기반의 실시간 폴더 감시 및 즉각 자동 동기화
- **RoboVault**: Windows DPAPI 제로-로그인 기반의 안전한 암호화 NAS 자격 증명 금고
- **RoboTimeMachine**: NTFS 하드링크 기술을 응용하여 디스크 용량을 **최대 90% 절약**하는 타임머신 스냅샷 보관소

### 4. 🌐 NAS & 네트워크 드라이브 원클릭 무인 자동 로그인
- 시놀로지, QNAP, 윈도우 파일 서버 등 SMB 공유 폴더 접속 시 발생하는 인증 오류를 방지하기 위해 **Windows 자격 증명 관리자(`cmdkey`) 및 SMB 세션(`net use`) 2중 인증**을 자동으로 구성해 줍니다.
- 방화벽 차단으로 인한 연결 실패를 막아주는 **방화벽 예외 규칙 원클릭 등록** 기능도 함께 제공됩니다.

### 5. ⏰ 윈도우 작업 스케줄러(`schtasks`) 무인 백업 연동
- 매일, 매주, 매월 특정 시간 또는 PC 부팅 시 **사용자가 자리를 비워도 백업이 스스로 실행**되도록 윈도우 작업 스케줄러 등록 XML과 스크립트를 즉시 생성·등록합니다.

### 6. 🧹 기간별 / 용량별 오래된 백업 파일 자동 정리 (Auto Cleanup)
- "30일 이상 지난 구버전 파일 자동 삭제", "대상 드라이브 여유 공간이 부족할 때 오래된 백업부터 순차 정리" 등 백업 드라이브의 용량 부족 걱정을 원천 차단합니다.

### 7. 💻 개발자를 위한 C# WPF (MVVM) 독립 프로젝트 소스 100% 자동 생성
- 현재 GUI에서 설정한 모든 옵션, 폴더 경로, 스레드 설정이 그대로 반영된 **C# 12 / .NET 8 WPF MVVM 완전한 독립형 프로젝트** 소스를 원클릭으로 다운로드하여 사내 업무 자동화나 맞춤형 솔루션으로 손쉽게 확장할 수 있습니다.

## 🛠️ 간단 사용법 3단계

1. **프로그램 실행 및 폴더 선택**
   - 상단에서 백업할 **원본 폴더(Source)** 와 저장할 **대상 폴더(Destination)** 를 드래그 앤 드롭 또는 폴더 찾기로 지정합니다.
2. **백업 모드 선택**
   - **미러 백업(`/MIR`)**: 원본과 대상을 100% 동일하게 일치시키며 삭제된 파일도 대상에서 정리합니다.
   - **증분 백업**: 새롭게 생성되거나 수정된 파일만 골라서 빠르게 덮어씁니다.
3. **[백업 시작] 버튼 클릭**
   - 하단 실시간 콘솔 창에 전송 속도, 파일 수, 남은 바이트, 오류율이 한눈에 표시되며 초고속 백업이 완료됩니다.
