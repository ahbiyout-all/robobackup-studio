RoboBackup Studio

Windows 최강 성능 Robocopy GUI & C# WPF 자동 생성 솔루션

복잡한 Robocopy 명령어를 단 한 번의 클릭으로! 전문가급 백업 인프라를 구축하고 실제 작동하는 C# WPF 소스 코드까지 얻을 수 있는 유일한 도구, RoboBackup Studio를 소개합니다.

🚀 독보적 퍼포먼스 Windows 네이티브 Robocopy 엔진을 사용하여 멀티스레드 기반의 가장 빠른 복사 속도를 보장합니다.
📈 성능 분석 센터 (Recharts) 전송 속도(Mbps) 및 처리 파일 수의 시계열 추이를 차트로 정밀 시각화하고 과거 세션을 비교합니다.
🛠️ C# 소스 생성기 설정한 모든 옵션과 UI 로직을 실제 Visual Studio에서 빌드 가능한 C# WPF MVVM 코드로 내보냅니다.
🛡️ 무인 자동화 시스템 Windows 작업 스케줄러와 연동하여 백그라운드 무인 백업 및 오래된 파일 자동 정리를 수행합니다.
🔔 실시간 지능형 알림 트레이 백그라운드 구동 지원 및 작업 실패 시 즉시 원격/로컬 알림을 통해 데이터 안전을 지킵니다.
📑 텔레메트리 리포트 백업 상세 분석 텍스트 리포트(.txt) 및 CSV/JSON 텔레메트리 데이터를 원클릭으로 다운로드합니다.

📢 최신 업데이트 (v2.19.1)

  • WPF 런타임 프로그레스바 바인딩 예외 긴급 패치: 읽기 전용 텔레메트리 속성 바인딩 시 발생하던 RangeBase.Value 예외를 Mode=OneWay로 완벽 해결
  • Recharts 성능 분석 센터 신설: 실시간 전송 속도(Mbps / MB/s) 및 누적 처리 파일 수의 시계열 차트 시각화
  • 과거 백업 실행 이력 비교: 과거 백업 세션 간 평균 속도, 피크 속도, 처리 파일 수 비교 차트 및 텔레메트리 보존
  • 텔레메트리 데이터 CSV/JSON 내보내기: 원시 성능 측정 데이터를 엑셀 및 JSON 파일로 즉시 다운로드
